\section{System Model}

\subsection{Participants}

TrustAuditFlow includes five roles.

\textbf{Data owner.} The data owner registers a data object, defines the audit policy, and generates initial commitments.
\textbf{Off-chain storage nodes.} These nodes store data shards, parity shards, or computation evidence, and respond to audit challenges.
\textbf{Auditors.} Auditors sample shards or evidence objects, check hashes or proof outputs, and submit audit summaries.
\textbf{Audit committee.} A committee is selected from trusted nodes and confirms routine audit summaries, recovery states, and trust-score updates.
\textbf{Consortium chain.} The chain stores object states, Merkle roots, hash-chain anchors, recovery events, and node trust states.

\subsection{On-Chain and Off-Chain Boundary}

The system follows an off-chain computation and on-chain anchoring design. Off chain, nodes perform sharding, erasure coding, local storage, sampled checking, recovery, and full evidence retention. On chain, the system records compact evidence: object identifiers, coding parameters, Merkle roots, batch audit summaries, recovery states, and trust-score updates. The chain is not used as a high-frequency proof executor. It serves as a trusted timeline, a state anchor, and an accountability ledger.

\subsection{Objects and Commitments}

Let a data object $D$ be encoded into $k$ data shards and $m$ parity shards. The hash of shard $s_i$ is $h_i=H(s_i)$. The system builds a Merkle tree over all shard hashes and obtains a root $R_D$. The on-chain object state stores
\begin{equation}
  \langle id_D, k, m, R_D, policy \rangle,
\end{equation}
where $policy$ contains the sampling rate, audit interval, risk level, committee size, and recovery rule.

Off-chain audit evidence is organized as a hash chain. For an audit event $e_t$, the chain state is
\begin{equation}
  c_t = H(c_{t-1} \parallel e_t).
\end{equation}
The chain periodically anchors $c_t$ or a batch Merkle root of events. This makes later deletion or modification of off-chain evidence detectable as long as the anchored state remains available.
