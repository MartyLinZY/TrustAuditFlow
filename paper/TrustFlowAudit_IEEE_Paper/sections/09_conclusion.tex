\section{Conclusion}

This paper presented TrustAuditFlow, a lightweight extension of the BLoP full-node trusted audit model for blockchain-based distributed data verification in data circulation. The design keeps BLoP as the high-assurance baseline and adds a risk-aware committee path for routine audit events. It separates off-chain verification and recovery from on-chain anchoring, uses Merkle roots and hash-chain states for traceability, connects anomaly detection with erasure-code-assisted recovery, and updates node trust scores after audit outcomes. The current version provides the problem formulation, system model, protocol design, and security-cost analysis. It does not yet make empirical performance claims. Completing the evaluation and replacing hash sampling with stronger PDP/PoR-style verification are necessary before the work can be considered ready for a CCF-A-level submission.
